# 星燈紀行 · Starlight Chronicle

繁體中文、單人、回合制奇幻 RPG。以 Three.js 的立體場景、原創像素角色、動態陰影、霧與泛光，呈現可在桌面瀏覽器遊玩的 HD-2D 風格冒險。

[線上遊玩](https://kaicsii.github.io/rpg-game/)

## 啟動

需要 Node.js 22.12+。

```sh
npm ci
npm run dev
```

開啟終端顯示的本機網址（預設 http://localhost:5173）。

```sh
npm test        # 戰鬥、機關、存檔與完整戰役模擬
npm run build  # TypeScript 檢查與正式靜態建置
npm run preview # 預覽 dist
```

部署時把 `dist/` 放到支援靜態檔案的網站根目錄。無需後端、API 金鑰或帳號。若部署到子目錄，先在 Vite 建置時設定 `--base`。

GitHub Pages 由 `.github/workflows/deploy.yml` 部署：推送 `main` 後會自動安裝依賴、測試，以 `--base=/rpg-game/` 建置並發布 `dist/`。儲存庫的 Settings → Pages → Source 使用 GitHub Actions；更改儲存庫名稱時也須更新建置路徑與上方遊玩連結。

## 操作

- WASD / 方向鍵：依畫面方向移動；窄螢幕提供觸控方向鍵，按住移動、放開停止，並可點「互動」與附近人物或物件互動。
- E / Enter：與附近人物、機關、星燈、道具互動或推進一頁對話。
- 對話中按 Esc：略過整段對話，仍會正常完成任務、獎勵或區域切換。
- 戰鬥中按 A 或右上角按鈕：切換自動攻擊；按 Esc 可停止。自動攻擊使用普通攻擊並自動選擇存活敵人，不消耗 MP 或道具。正在播放的動作會完成後再停下；每場戰鬥與重試預設關閉。
- 探索時點底部角色卡切換帶隊；未聚焦按鈕時可按 Tab 切換，選單中的 Tab 仍用於焦點導覽。查看古橋的舊提燈時，帶隊角色決定可採取的行動；切換不影響戰鬥能力。
- M：區域地圖；J：任務日誌；C：隊伍；I：行囊；Esc：暫停 / 返回。
- 戰鬥與選單可用滑鼠，也可用 Tab / Shift+Tab 與 Enter。長對話可在文字區內捲動，或用 Tab 聚焦文字後以方向鍵捲動；底部操作按鈕固定保留。
- 藍色星燈：完全恢復生命與魔力、保存進度、設定敗北返回點。

短篇與中篇共用一個自動欄位和一個手動欄位。開始新旅程後，自動進度會覆蓋自動欄位。如要保留上一趟旅程，請先存到手動欄位。「繼續旅程」會標示每個存檔的篇別。存檔保存在目前瀏覽器的 localStorage，清除網站資料會刪除。設定、任務、機關、寶箱與已擊敗敵人均保存；戰鬥不在中途存檔。

## 完整旅程

在標題畫面選「開始中篇」即可遊玩。中篇包含八個區域、54 場主線、12 條支線、24 篇環境故事、8 段談心，以及 6 場返鄉尾聲。主線會從霧鐘村出發，經森林、水道、灰港驛站、風鳴高地、白頁檔案館、回村重訪、眠鐘迴廊，抵達月蝕鐘塔。區域開放後可在地圖（M）選擇接駁。中篇角色上限為九級。章節與支線的原稿見 [中篇完整冒險劇本](STORY_MEDIUM.md)。

「啟程」進入原四區短篇，流程如下。 [短篇劇本原案](STORY.md)

1. **霧鐘村**：與守燈婆婆交談取得主線。廣場南側的舊提燈可由莉恩讀取記憶，或由洛恩辨認暗號。任一線索可向婆婆交付「橋上未響的鈴」，日誌可收錄兩條線索，獎勵只領一次。
2. **螢光森林**：點亮三盞路燈、挑戰北方的古橋守木，取得星火與武器強化。森林有獨立主題曲；抵達古橋時有可略過的登場演出與守木戰曲。
3. **沉星水道**：開啟兩個水閘，找回西北方的洛恩記憶，擊敗守潮者。
4. **月蝕鐘塔**：星盤調為西二、東一、北三；擊敗雙階段守鐘人，再與北方星台互動。
5. 結局後可繼續探索並回村交付支線。一般敵人不重生、無需刷經驗，角色最高五級。

戰鬥包含角色出手姿勢、斬擊突進、火焰／星光飛彈、受擊後仰與命中特效，搭配各屬性的原創合成音效。攻擊依序播放，期間無法重複輸入指令；「減少動態效果」會停用突進、後仰與飛彈，改用短暫的命中提示。

多數敵人每三回合重擊，命中弱點兩次可破盾。古橋守木有三格護盾，弱點在命中後揭露；蓄力時護盾最多剩兩格，也會露出斬擊破綻。若在橫掃前破盾，可保護全隊並保留下一輪追擊窗口。防禦恢復 4 MP；共鳴滿 100 可施放聯手技。敗北可重試，或保留探索進度返回星燈。

## 專案結構

- `src/data.ts`：具型別的區域、遭遇、敵人、技能、物品與劇情。
- `src/medium-content.ts`、`src/medium.ts`：中篇關卡、支線與進度規則。更新劇本原稿後可執行 `node scripts/extract-medium-story.mjs` 重新產生對話資料。
- `src/game.ts`：不依賴渲染的戰鬥、進度、機關與存檔邏輯。
- `src/world.ts`：立體場景、像素動畫、碰撞、光影、粒子與攝影機。
- `src/main.ts`：遊戲狀態、互動、對話、HTML 選單與鍵盤操作。
- `src/audio.ts`：原創五聲音階旋律與合成音效。
- `src/game.test.ts`：Node test runner 的確定性測試。

開發模式在 `window.__starlight` 提供固定場景、戰鬥與對話測試入口，以重現首領、存讀檔及結局情境；正式建置透過 Vite 的 DEV 常數移除。

## 素材與授權

莉恩與洛恩的原創人設使用內建 imagegen 生成，再依人設轉為四方向像素圖。高清稿、像素原圖與提示詞摘要保存在 [角色美術資料夾](art/characters/README.md)。遊戲載入兩張共約 68 KB 的透明圖集，以最近鄰取樣顯示每個 52 × 64 像素的動作格。村民、敵人、場景與音效仍由本專案程式產生。音訊在玩家第一次操作後才啟動。

字體採 Google Fonts 的 Noto Serif TC 與 Noto Sans TC（SIL Open Font License），無網路時由本機 serif / sans-serif 備援。圖示為內嵌原創 SVG。Three.js 使用 MIT 授權；其他依賴的授權見各套件。

## 範圍與驗證

短篇與中篇均已跑完主線的自動測試。中篇可只打教學戰與七場主要對抗便通關，結局後仍可回訪各區並補做支線。真人首次遊玩的時長仍待實測。

效能目標為一般筆電 1080p / 60 FPS；實際結果取決於 GPU 與瀏覽器。細緻畫質包含泛光、陰影、粒子；輕盈畫質關閉上述效果。提供減少動態效果與音量控制，以及窄螢幕觸控移動。

瀏覽器測試與已知限制見 [QA.md](QA.md)。

## 響應式介面

遊戲填滿瀏覽器當下可視範圍，HUD 依螢幕安全邊距排版。畫面越寬，相機能看到越多左右場景。調整視窗或旋轉手機時，視野即時更新，繪圖緩衝區在尺寸穩定 150 毫秒後調整。長文字、選單與戰鬥指令可在面板內捲動。

Canvas 的內部像素尺寸依 CSS 尺寸與裝置像素比計算。輕盈畫質會關閉陰影、泛光和粒子。探索時可點擊或輕觸場景中的同伴切換帶隊角色，靠近 NPC 或設施後可直接點擊互動。點擊民宅或鐘塔會顯示名稱。

## 探索引導與戰鬥提示

探索時，八格內的村民、商人、星燈與已發現物件可在場景上顯示標記。標記會避開介面，優先顯示可互動對象與主線目標；仍需走到約 2.2 格內才可互動。

右下角為北向小地圖，可點「展開 M」、任務卡的「地圖」，或使用 M 開啟完整地圖。地圖上以白點標示玩家、金星標示主線目標、菱形標示村民、方形標示商店、青點標示星燈。出口永久可見。寶箱、草藥、記憶與故事接近四個世界單位後揭露，已領取物品隱藏、已讀故事保留灰色標記。地圖不提供自動尋路。

敵人卡會預告重擊回合，並顯示破盾、碎甲與首領階段；角色卡顯示防禦與護衛。點擊狀態可查看完整說明。自動攻擊預設在任一隊員 HP ≤30%（含倒地）時停止，可在旅途設定或戰鬥指令下方關閉保護；正在播放的行動與敵方回應會正常完成，不自動使用治療或道具。

帶隊角色、發現記錄與低血量保護設定均可保存。舊版 version 1 存檔會補入莉恩、空發現記錄與開啟保護，不會清除既有任務、物品或戰鬥進度。
